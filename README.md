# Krunal Akbari portfolio

Run `npm run build` to generate the static website in `dist/`. No dependencies need installing.
Run `npm start` to preview the build at http://localhost:5173.

For Netlify or Cloudflare Pages, use build command `npm run build` and output directory `dist`. For Vercel, select Other, set the build command to `npm run build`, and output directory to `dist`.

Before public launch, replace `hello@yourdomain.com` and the booking/social links in `index.html` with your real details.
